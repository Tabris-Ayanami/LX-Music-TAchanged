# 轻量 UI 与功能优化设计

日期：2026-08-19  
分支：`hybrid-native`

## 目标与边界

一次性交付四项已确认改进：搜索框 gooey 动画、Discover 下一首镜像布局、本地歌曲统一菜单与沉浸式编辑页、Apple Music 动态封面修复。

本轮不引入 React、Tailwind、framer-motion 或新的全局 token 系统；复用现有 Vue、Less、主题变量和基础组件。只新增三个小型复用单元：布尔开关、本地歌曲菜单 action 工厂、动态封面视频组件。不重写播放器内核或各页面独特布局。

## 1. 搜索框

- 保留 `SearchInput.vue` 的搜索、联想、键盘和加载逻辑。
- gooey SVG 滤镜只作用于胶囊与分离圆球的背景形状；描边、输入、文字和图标位于滤镜外。
- 搜索图标只有一个可见状态源，展开时平滑移动/显现，避免内外图标交叉闪烁。
- 聚焦态使用现有主题 focus 颜色，不让主色描边进入滤镜。
- `prefers-reduced-motion` 下关闭位移、blur 与旋转以外的非必要动画。

验收：输入和展开过程无蓝色竖线、无双图标闪烁；搜索、清空、联想、Enter、方向键行为不变。

## 2. Discover 下一首镜像

- `.npTabNext` 的封面在折叠和展开状态均以右边缘为锚点，展开后保持 `right: 14px`。
- 下一首的信息区右对齐，播放按钮置左；上一首和当前歌曲不变。
- 使用现有动画时长、曲线和 reduced-motion 规则。

验收：右侧卡片展开时封面只做小幅位移，不再横跨展开后的卡片。

## 3. 本地歌曲菜单与编辑页

### 统一菜单

共享 action 工厂按上下文生成：播放、下一首播放、添加到歌单、编辑歌曲信息、匹配或重新匹配歌词、在资源管理器中显示、复制“歌曲名 - 歌手”。自建歌单上下文额外保留“从当前歌单移除”；任何上下文都不提供删除音频文件。

`LocalMusic` 的歌曲、专辑详情、歌手详情和行星视图，以及普通 `MusicList` 中的本地歌曲，使用同一 action 定义。歌词状态决定只显示“匹配”或“重新匹配”之一。

### 编辑页

沿用 `MetadataEditModal` 和现有 Main 进程 copy-and-swap 写入，不改变元数据 IPC 合同。视觉采用已确认的 C 方案：

- 顶部为大封面、标题、歌手、专辑与年份摘要；
- 页签为“信息 / 歌词 / 文件”；
- 信息页按“主要信息、分类与排序、备注”分组；
- 歌词页继续复用 `LyricsMatchPanel`；
- 文件页只读显示格式、码率、采样率、时长和文件路径；
- 保存期间禁止关闭，失败时继续保证原音频不被替换。

## 4. Apple Music 动态封面

### 根因

Apple 搜索结果中的歌曲记录未携带专辑 relationship；现实现把歌曲 ID 当成专辑 ID。实测 `Shape of You` 歌曲 ID `1193701392`，正确专辑 ID `1193701079`，后者包含有效 `editorialVideo` 和 H.264 HLS 变体。

### 修复数据流

1. 搜索时记录命中资源类型和 storefront。
2. 若命中歌曲且缺少 albumId，请求同 storefront 的 `songs/{id}`，读取 `relationships.albums.data[0].id`。
3. 使用该 albumId 优先请求同 storefront 的 `albums/{id}?extend=editorialVideo`，再按现有 storefront 顺序回退。
4. 沿用 H.264 优先的 HLS 选择、同歌曲请求去重和 50 项有限缓存。
5. 任一环节失败或专辑无动态资源时返回静态封面，不弹错误打断播放。

### 开关与生命周期

- 增加 `BaseSwitch`，在外观设置显示“Apple Music 动态封面”。
- 新布尔设置键为 `playDetail.appleDynamicCover`，默认 `true`，所以旧配置缺少该键时也默认开启；关闭后不发起 Apple 查询。它是动态封面的唯一启停依据。现有 `playDetail.coverType` 只为旧配置兼容而保留，设置界面和渲染逻辑不再读写它。
- 移除自动询问弹窗。启用时直接显示动态封面，无资源则回退静态封面。
- `DynamicArtworkVideo` 统一 poster、错误回退、autoplay/muted/loop 和 active 生命周期。
- 播放详情隐藏、切歌、组件失活或功能关闭时卸载 `<video>`，释放网络与解码资源；重新打开时按缓存恢复。

## 复用与性能约束

- 不新增运行时依赖。
- 不建立全局设计系统，只让新增组件使用现有 `--shell-*`、`--color-*` 和 motion 变量。
- gooey 滤镜区域从整个交互内容缩小到两个背景形状。
- 动态封面关闭时零查询；页面隐藏时零动态视频节点。
- 不宣称整体内存必然下降；只验证请求次数、视频节点生命周期和功能正确性。

## 错误处理

- Apple token、搜索、专辑详情、HLS 或视频播放错误均静默回退静态封面，并保留开发日志。
- 本地元数据读取失败显示错误态；写入失败沿用原始文件保护与用户提示。
- 菜单 action 在执行前关闭菜单，异步失败不得留下悬挂菜单状态。
